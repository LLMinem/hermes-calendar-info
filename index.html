The actual application

A private calendar assistant.

Hermes Calendar is a personal integration between Hermes Agent and Google Calendar, using the open-source gog CLI. Once authorized and configured, it can read calendar entries and, when instructed by its owner, create, update or delete events. Its main purpose is to maintain a calendar called “Reality”: a record of what actually happened rather than another optimistic to-do list.

The integration is being configured on the owner’s VPS, with use on the owner’s Mac planned as well. It is not a public service and has no public signup. This site does not run the assistant, receive OAuth callbacks or provide access to any calendar.

The calendar is private. The explanation of why the calendar is private is, for administrative reasons, a website.

Access and control

The integration initially requests Google Calendar access only. Google’s Calendar permission can cover more than one calendar; it is not a technical restriction to the Reality calendar. The assistant’s instructions restrict operations to the task and target calendar authorized by the owner. Other Google services are not part of this initial setup.

Hermes Calendar is independently operated by its owner. It is not affiliated with or endorsed by Google or the developers of Hermes Agent or gog CLI.

Privacy policy · Effective October 14, 2026

The serious part.

This policy describes the intended operation of the private Hermes Calendar integration and this informational website. It does not grant access to any account. Access begins only after the account owner authorizes the integration.

What information is accessed

The integration may access calendar names and identifiers, event identifiers, titles, descriptions, dates, times, time zones and other event fields needed to perform and verify the owner’s requests. Existing events may contain personal information or attendee details. OAuth credentials and access tokens are used to authenticate requests.

Why information is used

Calendar information is used to answer the owner’s questions, reconstruct activity timelines, carry out requested calendar changes, avoid duplicates and verify the saved results. Calendar data is not sold, used for advertising or published on this website.

Where information is processed and shared

Google processes API requests and stores the calendar. The integration runs on the owner’s devices and server. Relevant calendar content may be included in prompts sent to the AI provider configured in Hermes for the requested task. Such processing is subject to that provider’s applicable terms, account settings and retention policies. This integration does not independently guarantee that every configured provider offers zero retention or excludes training.

The owner’s Hermes profiles can share the same authorized Google connection. Credentials are stored separately from website source code. They are not intentionally included in model prompts or public pages. Calendar content can remain in private agent conversations, operational logs, temporary files or backups.

Retention and deletion

Calendar events remain in Google Calendar until changed or deleted by the owner or through an authorized request. Local conversations, logs and backups follow the owner’s configured retention practices; there is no promised automatic deletion period. The owner can remove local records and stored credentials. Revoking access stops future authorized API access, but does not automatically erase existing calendar events or previously retained records.

Your controls

The owner can revoke the integration’s access through Google Account connections, remove its local credentials, or stop using the assistant. For questions about this private integration, contact the owner through the project issue tracker. Issues are public: do not include calendar content, personal details or credentials.

This website

This static site has no login, forms, analytics scripts, advertising, tracking pixels or application cookies. It is hosted by GitHub Pages. GitHub may log visitor IP addresses and other request information for security and service operation, as described in the GitHub Privacy Statement. No calendar content or OAuth credentials are sent to this website by the integration.

Google API data policy

Hermes Calendar’s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements. The operator must configure the assistant and any downstream AI processing consistently with these requirements before using Google data.

Changes

If the integration’s access or data practices change, this page will be updated. This policy is specific to this personal tool, not a general policy for Hermes Agent, gog CLI or Google.
